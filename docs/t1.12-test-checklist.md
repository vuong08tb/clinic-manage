# T1.12 — Review và checklist kiểm thử

## 1. Yêu cầu gốc

> Mọi API ghi dùng Form Request. Response dùng API Resource. Envelope:
> `success/message/data` (`errors` với 422, `meta` khi paginate). Exception Handler trả
> JSON cho API, không trả HTML.

Nguồn đối chiếu:

- `docs/ke-hoach-chi-tiet.md`, mục T1.12.
- `skills/backend.md`, mục 1, 2 và checklist review backend.
- `README.md`, mục Envelope JSON và ma trận HTTP status.

## 3. Chuẩn response cần kiểm tra

### 3.1. Success

```json
{
  "success": true,
  "message": "Logged in",
  "data": {}
}
```

Không được có:

- `errors` trong success response;
- `data.data`;
- HTML hoặc redirect.

### 3.2. Validation/business rule 422

```json
{
  "success": false,
  "message": "The given data was invalid.",
  "errors": {
    "email": [
      "The email field is required."
    ]
  }
}
```

Điều kiện bắt buộc:

- HTTP status là 422, không phải 400.
- `success` là `false`.
- `errors` chứa key theo field.
- Không có `data`.
- Content-Type là JSON.

### 3.3. Pagination

```json
{
  "success": true,
  "message": "Users retrieved",
  "data": [],
  "meta": {
    "current_page": 1,
    "from": 1,
    "last_page": 2,
    "per_page": 15,
    "to": 15,
    "total": 20
  }
}
```

Không được có `data.data`. Contract hiện tại chủ động không trả `links`.
